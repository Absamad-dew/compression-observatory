# Compression Observatory

Воспроизводимый стенд для **обычных lossless-кодеков стандартной библиотеки Python**: gzip, zlib, bz2, lzma. Python 3.11+, без зависимостей во время работы.

```sh
python -m pip install .
compression-observatory generate corpus --seed 1729 --records 2000
compression-observatory bench corpus --warmups 1 --repeats 5 --json results/run.json --html results/report.html
```

Каждая итерация проверяет побайтовое восстановление и SHA256. JSON содержит исходные повторы, размеры, медиану, p95 и CV. Суммарный коэффициент считается по общим байтам; время — как медиана сумм по файлам в каждом повторе. HTML/SVG полностью автономный, без скриптов и внешних ресурсов.

Можно явно указать свой каталог. Ограничения по умолчанию: 1000 файлов, 16 МиБ на файл, 64 МиБ суммарно. Символические ссылки и Windows reparse points отклоняются. Отчёт содержит имена файлов и хеши: проверяйте их перед публикацией.

Это публичный универсальный инструмент, написанный с нуля. Здесь нет частного алгоритма, исходников R&D или закрытых корпусов. Синтетический пример демонстрирует методику измерения и **не подтверждает никаких результатов частных исследований**. Результаты зависят от корпуса, среды и фоновой нагрузки; Pareto-флаги не являются статистической проверкой превосходства.

Подробная методика и ограничения: [English README](README.md). [Пример отчёта](examples/report.html), [сырые измерения](examples/run.json), [происхождение прогона](examples/PROVENANCE.md). Лицензия MIT.
